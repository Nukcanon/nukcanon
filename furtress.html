FURTRESS

Furtress 퍼트리스 · 꼬마 왕국

동물 왕국의 왕이 되어 길을 따라 병력을 보내 마을과 성을 차지하는 실시간 전략 게임입니다.
2~40명이 2~8개 나라로 나뉘어 함께하고, 빈자리는 AI가 채웁니다. 혼자서 AI와도 할 수 있습니다.

설치 없이 바로 시작

설치가 차단될 때

설치 파일에 코드 서명이 없어 Windows가 경고합니다. 악성 코드가 발견된 것은 아니며, 서명 없는 새 파일에 나타나는 기본 보호 기능입니다.

파란 창 "Windows의 PC 보호"

추가 정보를 누른 뒤 실행을 누르세요.

"스마트 앱 컨트롤이 이 앱을 차단했습니다"

파일마다 허용할 수 없습니다. 설치하려면 기능을 꺼야 합니다.

  1. 설정 → 개인 정보 및 보안 → Windows 보안을 엽니다.
  2. 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끔을 고릅니다.
  3. 설치 파일을 다시 실행합니다.

참고: 최신 Windows 11에서는 나중에 같은 곳에서 다시 켤 수 있지만, 다시 켜면 Furtress 설치판도 실행이 막힙니다. 끄고 싶지 않으면 위 웹에서 바로 하기로 설치 없이 하세요(인터넷 방과 혼자 하기).

어떻게 하나요

방 만들기

  1. 혼자 하기: 나라 수와 AI 난이도를 고르고 바로 시작합니다.
  2. 방 만들기: 방 번호가 나오면 친구들에게 알려 줍니다. 친구들은 방 들어가기에 번호를 넣습니다.
  3. 대기실 위쪽의 확인 글자가 방장 화면과 같은지 확인한 뒤, 방장이 시작을 누릅니다.

게임 진행

  1. 내 거점을 눌러 고르고 보낼 곳을 누르면 병력이 출발합니다. 아래 25·50·100%로 보낼 양을 정합니다.
  2. 마을·성·탑을 차지해 점수를 모으고, 동맹을 맺거나 깨며 목표 점수를 먼저 지킨 나라가 이깁니다.
  3. 영웅을 움직이고 기술을 써서 전투를 돕습니다. 기술 자동을 켜면 알아서 씁니다.

인터넷 방 · 같은 와이파이 방

  • 인터넷 방: 웹판에서 만들고 들어갑니다. 같은 망의 기기끼리는 서로 직접 연결하고, 안 되면 인터넷 중계로 이어 줍니다.
  • 같은 와이파이 방: 방장만 설치판을 설치합니다. 설치판을 실행한 PC가 방 서버가 되어 인터넷이 막힌 곳에서도 할 수 있고, 같은 망의 방 목록이 게임 창에 자동으로 뜹니다. 친구들은 검은 창에 나오는 「다른 기기」 주소로 브라우저에서 들어옵니다. Windows 방화벽 창이 뜨면 「개인 네트워크」를 허용하세요.
  • 모든 통신은 게임 안에서 종단 암호화됩니다. 방장이 나가면 다른 사람이 이어받아 경기가 계속됩니다.
  • 회원 가입이나 개인 정보 입력이 없습니다. 별명은 게임 안에서만 쓰입니다.
