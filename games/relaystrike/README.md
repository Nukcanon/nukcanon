# RelayStrike LAN 0.1.0

Windows x64용 내부망 FPS의 첫 플레이 가능한 개발 버전입니다. 실행에는 Python·Godot 편집기·외부 인터넷·온라인 계정이 필요 없습니다. 그래픽과 사운드는 간단한 자체 제작 자산이며, 상용 FPS의 에셋을 사용하지 않습니다.

## 빠른 시작

1. ZIP을 모두 풀고 `RelayStrike.exe`를 실행합니다. `.pck`는 exe 옆에 있어야 합니다.
2. 한 PC에서 **방 만들기** → 모드·맵·인원·스킬 등을 선택합니다.
3. 다른 PC는 **내부망 방 찾기 / IP로 접속**을 사용합니다. 검색되지 않으면 방장 화면에 표시된 IP를 직접 입력합니다.
4. 대기실에서 병과·장비를 고르고 방장이 경기를 시작합니다.
5. 혼자 확인하려면 **혼자 연습**을 선택합니다. 연습 봇은 간단한 교전 AI이며 전문적인 전술 AI는 아닙니다.

Windows 방화벽에서 이 게임의 내부망 통신을 허용해야 합니다. UDP 27888(게임), 27889(방 검색)를 사용합니다. 학교 네트워크에서 PC 간 통신을 차단했다면 관리자에게 해당 연결 가능 여부를 확인해야 합니다. 외부 인터넷에 포트를 공개할 필요는 없습니다.

## 조작

| 키 | 동작 |
|---|---|
| WASD | 기본 빠른 걷기 |
| Shift | 달리기. 사격 전환 준비 약 0.5초 |
| Ctrl | 앉기. 엎드리기 없음 |
| Space | 점프 |
| 왼쪽 클릭 / 오른쪽 클릭 | 발사 / 정조준 |
| R / 1 / 2 | 재장전 / 주무기 / 보조무기 |
| F | 전투 메딕 회복탄, 2초 간격 |
| E 유지 | 떨어진 무기의 탄약 회수, 목표 지점 설치·해체 |
| Q | 병과 스킬, 공병 포탑 설치·강화 |
| G / V | 가젯 사용 / 통제병 연막·섬광 선택 |
| B | 장비 선택. 대기실·탈락 후·폭탄 구매 시간에 적용 |
| Tab / Esc | 점수판 / 메뉴 |

오른쪽 위에 FPS·서버 왕복 핑을 표시합니다. 방장은 HOST로 표시됩니다.

## 주요 규칙

- 최대 전투 참가자 32명. 전용 서버는 참가 인원에 포함되지 않습니다.
- 개인전, 팀 데스매치, 제한 부활 팀전, 거점 점령, 장치 설치·해체.
- 최초 팀 자동 배치/직접 선택. 경기 종료 후 같은 팀/무작위/기록 기반 재편성.
- 병과 사용과 특수 스킬 사용을 따로 선택합니다. 스킬 OFF여도 회복 무기·수리 도구·엄폐물·연막·섬광 등 장비 기능은 유지됩니다.
- 체력 100, 방어구 0/25/50. 방어구가 먼저 소모됩니다.
- 빠른 걷기·점프 시 탄 퍼짐 증가. 정조준·앉기는 정확도를 높입니다.
- 얕은 반투명 물은 수면 아래에 맞은 부위, 또는 물에 들어간 사람이 밖을 향해 사격할 때 피해를 50%로 줄입니다. 두 조건이 겹쳐도 25%로 추가 감소하지 않습니다.
- 맵 보급품은 현재 공격 무기의 최대 예비탄 중 25%를 지급하고 30초 후 재생성됩니다. 떨어진 무기에서는 남은 탄약을 회수합니다.
- 무한 탄약 옵션은 공격용 예비탄에만 적용됩니다. 재장전은 필요하며 의료·가젯 자원은 제한됩니다.
- 단순한 붉은 명중 입자와 탈락 밀림 연출. 탈락 모델은 6초 내 사라지고 무기는 최대 40초 남습니다.

## 병과

| 병과 | 주무기 | 장비 / 스킬 |
|---|---|---|
| 돌격 | 소총 4종 | 개인 보호 / 짧은 대시 |
| 정찰 | 저격 3종·지정사수 2종 | 수동 표식 / 감지 파동 |
| 중화기 | 기관총 2종 | 앉은 상태 거치 / 전방 보호 |
| 공병 | 샷건 3종 | 엄폐물 / 포탑. 권총 대신 수리 도구 선택 가능 |
| 통제 | 기관단총 4종 | 연막·섬광 / 둔화 구역 |
| 메딕 | 지속 회복기·의료 카빈 | 회복 팩 / 상태 정화 |

각 병과별 보조무기 6종과 공병 수리 도구를 포함해 총 27개 장비 데이터가 있습니다. 의료 카빈은 F로 20 회복, 2초 간격입니다. 메딕은 팀 1~6명 1명, 7~9명 2명, 10~12명 3명, 13~15명 4명, 16명 5명입니다.

## 공병

엄폐물: 내구도 250/500/800, 폭탄 모드 가격 300/600/1000. 공병당 동시 2개. 포탑은 공병당 1개, 충전 30초입니다. 기존 포탑 5m 이내에서 조준하고 Q를 누르면 강화합니다. 최초 설치 후 3회 강화, 최대 4단계입니다. 파괴 후 재설치하면 1단계이며 충전 시간은 초기화/환불되지 않습니다.

포탑은 공병 엄폐물 위로 포신이 노출되는 높이로 설치됩니다. 벽을 관통하지 않습니다. 탐지 범위는 25/30/35/40m이고 노출된 포탑 상부는 공격할 수 있습니다. 연막은 포탑 시야를 차단하고 섬광은 잠시 작동을 멈춥니다.

## 폭탄 모드 경제

시작 자금 800, 승리 3500, 패배 단계별 1900/3000/3300. 승리 시 패배 보상 단계가 하나 줄어듭니다. 최대 자금 8000. 구매 20초, 전투 150초, 설치 3초, 해체 5초, 설치 후 작동 40초. 3라운드마다 공격·수비를 바꾸고 경제를 초기화합니다. 먼저 7라운드를 이긴 팀이 승리합니다.

## 현재 검증 범위와 제한

- 핵심 규칙 자동 시험과 같은 실행 환경에서의 다중 ENet 접속 시험을 수행했습니다. `docs/TEST_REPORT.md` 참조.
- 실제 Windows PC 여러 대의 LAN 시험과 구형 내장그래픽 성능 시험은 아직 필요합니다. 특정 내장그래픽에서 32명 60FPS를 보장하지 않습니다.
- 그래픽·총기 애니메이션·음향은 기능 검증을 위한 초기 수준입니다. 상용 게임 수준의 완성된 연출은 아닙니다.
- 연습 봇은 길찾기·목표 수행·구매 전략이 제한적입니다. 모든 모드를 제대로 시험하려면 여러 사람이 접속해야 합니다.
- 서버 종료 시 방은 종료됩니다. 자동 서버 승계·음성 채팅·인터넷 매칭은 없습니다.
- 무기별 상세 반동 패턴과 정교한 애니메이션은 이후 보완 대상입니다. 제한 부활은 개인 목숨/팀 공용 부활을 선택하며, 탈락 후 왼쪽 클릭으로 아군 관전 대상을 전환합니다.

## 소스 수정·재빌드

Godot 4.4.1 Standard로 `project.godot`를 엽니다. 무기 수치는 `assets/weapons.json`, 모드·경제 규칙은 `scripts/game.gd`와 `rules.gd`, 맵은 `scripts/arena.gd`에서 수정합니다. GitHub 소스에서 빌드할 때는 `python tools/prepare_assets.py`를 먼저 실행해 오디오와 OFL 글꼴을 준비합니다. 배포 ZIP에는 준비된 자산이 포함되어 있습니다.

수정한 모든 클라이언트와 서버는 동일 버전으로 배포하세요. 런타임 설정은 `%APPDATA%/Godot/app_userdata/RelayStrike LAN/settings.cfg`에 저장됩니다.
