Internal N Crush 0.2.0 — 플레이 수정 업데이트

Windows x64 ZIP을 모두 압축 해제하고 InternalNCrush.exe를 실행하세요. 모든 참가자는 같은 버전을 사용해야 합니다. Python과 편집기 설치는 필요 없습니다.

- 사망 시 별도 관전 카메라 사용. 부활 후 잘못된 시점·사격 방향·맵 이탈로 보이던 오류 수정.
- 일반 감도와 정조준 감도 배율을 따로 조절·저장. F 스킬 / Q 메딕 회복 / E 상호작용.
- 기본 이동 7.4, 달리기 11.2, 정조준 이동 4.4m/s. 달리기 후 사격 전환 대기는 0.5초.
- 1 주무기 / 2 보조무기 / 3 가젯 / 4 통제병 추가 가젯. 선택 후 클릭으로 사용.
- 단발·연발·3점사 구분, 빈 탄창 자동 재장전, 무기별 재장전 시간·동작, 전환 동작.
- 무기와 장갑·팔 모델 재구성, 걷기·피격 반응, 총구에서 시작하는 탄 궤적, 가리지 않는 정조준 시야.
- 메뉴와 HUD 재구성. 구매 비용·장비 효과·가젯 수량·선택 상태 표시.
- 병과·장비 변경은 다음 부활에 예약 적용. 폭탄 모드는 다음 구매 시간에 비용 확인 후 적용.
- 일반 모드 기본 방어구 50. VECTOR-24 피해 28→24, 정밀 명중 배율 1.8→1.5. 봇은 몸통 중심 조준, 오차와 반응 지연, 사격 사이 휴식 적용.
- 무기 이름의 불필요한 설명 제거, 작은 탄약 표식, 물의 텍스트 표식 제거.
