# Internal N Crush 0.3.0 — playable alpha

- 기본 체력 100 / 기본 방어구 0. 선택 방어구는 장비 창에서 적용합니다.
- 6종 병과 캐릭터, 두 팀 색상, 12개 관절 동작과 27종 장비 모델. GLB 원본 포함.
- 창고 통로·컨테이너·엄폐물·항구 소품과 얕은 반투명 수로.
- 장애물을 우회하고 점령·설치·해체, 병과 회복·수리·가젯·스킬을 사용하는 봇.
- 봇 연습과 방 설정에서 하/중/상 난이도 및 최대 31봇 선택.
- 체력·탄약·목표·시야·최근 위험 지역에 반응하는 상황 판단. 학습 모델은 사용하지 않습니다.
- 속도/공중 상태/연사 누적에 따른 정확도, 짧은 점사와 긴 연사 회복 차이, 자체 T자 반동 패턴과 연동 십자선.
- 핵심/회귀/AI·조준/목표 수행 130개 검사, 별도 ENet 프로세스의 부활·사격, 32개 동시 접속 검증.

ZIP을 모두 풀고 InternalNCrush.exe를 실행하세요. Python이나 Godot 편집기 설치가 필요 없습니다. 모든 참가자는 0.3.0으로 맞춰야 합니다.

실제 Windows 여러 대의 LAN과 특정 내장그래픽 성능은 아직 검증하지 않았습니다. 모델·연출과 팀 전술은 계속 다듬을 개발 버전입니다.
