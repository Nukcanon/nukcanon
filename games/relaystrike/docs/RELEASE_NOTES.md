# Internal N Crush 0.4.0 — playable alpha

- 배경 패널이 있는 팀별 점수판과 개인전 순위. 32명 표시, 자기 행 강조, K/D/A·목표 점수.
- 대기실 자기 팀 선택, 방장의 전체 팀 편성. 경기 중에는 방장만 변경. 16 대 16에서는 두 참가자 교환 가능.
- 방 만들기·설정·장비 메뉴 개편. 캐릭터·주/보조무기·가젯 회전 미리보기와 성능·역할 설명.
- 전체화면/창 모드 및 해상도 설정 저장. 전체·총·발소리·장비/UI 음량 조절.
- 25종 무기별 발사음, 돌·금속·물의 발소리 각 4개와 전환·재장전·명중 소리.
- 정지·점사 후 탄 퍼짐과 T자 반동의 점진적 회복, 스코프 바깥 검은 마스크.
- 더 넓은 팀 색상, 간소화한 장식, 다듬은 모서리, 5가지 탈락 동작.
- 떨어진 물건은 들고 있던 실제 무기 모델. 탈락 모델 5.5초, 무기는 최대 40초 유지.
- LAN 메뉴 자동 검색, 연결 취소·재시도, 새 연결의 상태 번호 초기화, 조각 패킷 순서 변경 처리.
- 재접속 때 방 암호 설정이 사라지던 오류 수정. 8개 별도 클라이언트의 105초 유지·클라이언트 재접속·서버 재시작 검사와 32개 동시 접속 검사 통과.
- 기본 체력 100 / 기본 방어구 0 유지. 전투 중 장비 변경은 다음 부활에 적용.

ZIP을 모두 풀고 InternalNCrush.exe를 실행하세요. Python이나 Godot 편집기 설치가 필요 없습니다. 서버와 모든 참가자는 0.4.0으로 맞춰야 합니다.

실제 Windows PC 여러 대의 LAN, 장시간 접속, 혼잡한 Wi-Fi 및 특정 내장그래픽 성능은 아직 별도 검증이 필요합니다.
