# 검증 기록 — 2026-09-23

버전: RelayStrike LAN 0.1.0 / Godot 4.4.1

## 수행한 검증

- GDScript 프로젝트 가져오기·컴파일.
- 핵심 규칙 자동 시험 28개 통과: 메딕 정원, 연패 보상, 물 피해 감쇠, 부분 보급, 방어구/체력 피해, 처치/드롭, 부활 충돌체, 포탑 설치·강화·충전, 구매 및 병과 제한, 유한/무한 탄약 재장전, 달리기 후 사격 지연, 의료 카빈 2초 간격, 라운드 보상, 팀 편성 인원.
- Linux 실행 환경에서 ENet 서버 + 클라이언트 2개 연결·상태 동기화 확인.
- 같은 실행 환경에서 별도 프로세스 ENet 클라이언트 32개 동시 접속. 서버 인원 32 확인, 클라이언트 32개 정상 종료, 해당 시험의 오류 로그 없음.
- OpenGL Compatibility 실제 화면 렌더링 및 한국어 HUD 확인. 소프트웨어 렌더링 환경의 FPS는 사용자 내장그래픽 성능 지표로 사용하지 않음.
- Windows x64 실행 파일 및 리소스 패키지 내보내기.

## 시험의 한계

32개 접속 시험은 같은 실행 환경에서 진행한 짧은 기능 시험입니다. 32명의 활발한 실제 플레이, 서로 다른 Windows PC, Wi-Fi 혼잡·손실, 장시간 경기 및 특정 내장그래픽의 60FPS 성능을 입증하지 않습니다.

이 환경에서는 Windows 실행 파일을 실제 Windows에서 실행하지 않았습니다. 실제 학교/가정 내부망에서 2~4명부터 확인한 뒤 인원을 늘려 시험해야 합니다. 초기 그래픽·음향·봇은 추가 품질 개선과 플레이 밸런스 조정이 필요한 개발 버전입니다.

## 재현

`godot --headless --path . --editor --import --quit`

`godot --headless --path . --script tests/test_rules.gd`

전용 시험 서버: `godot --headless --path . -- --server --auto-start`

시험 클라이언트: `godot --headless --path . -- --connect=127.0.0.1 --nick=TEST01 --quit-test`

클라이언트마다 서로 다른 TEST 이름을 사용합니다. `--nick`은 시험용 프로필을 만들며 일반 UI에서는 각 PC에 별도 식별자가 저장됩니다.
