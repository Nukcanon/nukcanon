# 검증 기록 — 2026-09-23

Internal N Crush 0.6.0 / Godot 4.4.1

## 수정 전 재현

기존 관전 코드가 플레이어 Camera3D의 top_level과 전역 좌표를 변경하고, 부활 시 X/Z·회전을 초기화하지 않았습니다. 관전 후 부활 재현에서 카메라와 캐릭터 눈 사이 오차 111.32m를 관측했습니다. 관전 전용 카메라와 부활 시 로컬 변환 초기화로 수정했습니다.

## 0.4.0 수정 전 재현

8개 클라이언트 접속·재접속 시험에서 configure()가 공개 옵션으로 전체 설정을 덮어쓴 뒤 options.password가 없어져, 재접속 등록 시 스크립트 오류가 발생했습니다. 기본 옵션을 유지하고 로컬 암호를 보존하도록 수정한 뒤 같은 시험이 통과했습니다. 연결을 새로 만들 때 이전 상태 순서 번호와 수신 버퍼도 초기화합니다.

## 검증하지 않은 범위

이 환경에서는 Windows 실행 파일을 실제 Windows에서 실행하지 않았습니다. 실제 Windows PC 여러 대의 LAN, 패킷 손실과 Wi-Fi 혼잡, 32명의 활발한 플레이, 장시간 안정성, 특정 내장그래픽의 FPS 성능은 별도 확인이 필요합니다. 32봇 동시 전술, 장시간 교착 상태와 팀별 경제 균형은 추가 플레이 검증 대상입니다.
