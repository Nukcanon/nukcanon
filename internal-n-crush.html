Internal N Crush

함께 짜는 전술, 맞붙는 화력.
최대 32명이 즐기는 팀 FPS. 6개 병과와 실내·실외 31개 전장. 야외 사격장에서 장비를 익히고, 봇이나 다른 플레이어와 겨뤄 보세요.

플레이 가이드

  1. 바로 플레이로 브라우저에서 실행하거나, Windows ZIP을 모두 풀어 InternalNCrush.exe를 실행합니다. 웹 첫 실행에는 약 67MB를 내려받으며 WebGL 2를 지원하는 브라우저가 필요합니다.
  2. 메인 메뉴의 연습장이나 봇 전투로 시작하세요. 함께하려면 내부망 로비 → 방 만들기에서 맵·모드·인원을 설정합니다.
  3. 오퍼레이터와 장비를 고르고 경기를 시작합니다. 팀 데스매치·개인전·제한 부활·거점 점령·설치/해체를 지원합니다.

WASD 이동 · 마우스 왼쪽 사격 / 오른쪽 조준 · R 재장전 · Shift 달리기 / 두 번 눌러 슬라이딩 · Ctrl 앉기 · Space 점프 · 1–4 장비 · B 병과/장비 · G 가젯 · F 스킬 · E 문 열기·닫기 / 유지하여 설치·해체.

스마트폰·태블릿에서는 가로 화면으로 플레이하세요. 왼쪽 가상 스틱으로 이동하고 오른쪽 화면을 밀어 조준합니다. 스틱 끝까지 밀면 달리며, 발사·재장전·점프와 화면 아래 장비·스킬 버튼을 터치할 수 있습니다. 조준과 앉기는 한 번 눌러 켜고 다시 눌러 해제합니다. PC에는 터치 버튼이 표시되지 않습니다. 웹은 화면 해상도를 자동 변경하지 않으며, 모델과 재질을 간소화한 경량 그래픽을 사용합니다.

돌격 병과에서 파편 수류탄을 선택했다면 G를 누르고 준비한 뒤 놓아 던집니다. 안전핀을 뽑고 3초 후 폭발하므로 오래 들고 있으면 자신도 피해를 받습니다.

마우스 휠로 무기를 전환합니다. 저격 조준 중에는 배율을 조절하며 SCOUT은 4·8배, MONOLITH는 4·8·16배를 지원합니다. 모바일은 배율 ± 버튼을 사용합니다. 정찰병의 표식기는 장착 후 스코프 중앙의 적을 2초간 추적하면 팀 전체에 6초 동안 위치를 보여줍니다.

공병은 F·G로 설치 위치를 정한 뒤 클릭해 확정합니다. 빨간 위치에는 설치할 수 없으며, 내 포탑 가까이에서 F로 강화합니다. 설치·해체에서는 폭탄 운반자만 설치할 수 있고, 떨어진 폭탄은 공격팀이 E로 회수합니다.

방은 기본 8명·8인용 무작위 맵·무한 경기입니다. 정원 이상의 맵만 선택할 수 있으며, 무작위 맵 또는 순환을 켜면 같은 규모 안에서 맵이 바뀝니다. 설치·해체는 최대 12명이며 공수를 한 번씩 진행한 뒤 순환합니다.

설정 → 조작법에서 전체 키 안내를 볼 수 있습니다. 화면·감도·음량·유혈 효과(기본 꺼짐), HUD 크기·배경 농도를 설정에서 변경할 수 있습니다. Windows에서는 그래픽 품질도 선택할 수 있습니다. 전체 화면에서도 모니터 원본 이하의 게임 해상도를 선택할 수 있습니다.

멀티플레이 접속

  1. 참가자 모두 같은 내부망에 연결하고 같은 게임 버전을 실행합니다.
  2. 한 명이 내부망 로비 → 방 만들기로 방을 열면 나머지는 로비 목록에서 참가합니다.
  3. 장비와 팀을 선택한 뒤 방장이 경기를 시작합니다.

방이 검색되지 않으면 IP로 접속에서 방장의 IP와 비밀번호를 입력하세요. 실행 초기에 Windows 통신 허용창이 나타나면 개인 네트워크를 허용하세요. 허용 여부는 Windows가 저장하며 설치 경로나 정책이 바뀌면 다시 물을 수 있습니다. 게임 통신은 UDP 27888, 방 검색은 UDP 27889를 사용합니다. 다운로드 이후 같은 내부망에서는 외부 인터넷 연결 없이 플레이할 수 있습니다.

웹과 Windows가 함께하려면 같은 웹 호환 로비 주소에 연결합니다. 웹 내부망 로비는 같은 외부 네트워크 주소의 방을 보여 주며 Windows UDP 방과는 구분됩니다. Windows에서는 내부망 로비의 웹 호환 로비를 선택하세요. 브라우저 연습장·봇 전투는 방 목록 서버 없이 이용할 수 있습니다.

인터넷에서는 인터넷 로비에 운영자의 HTTPS 주소를 입력하고 방을 만들거나 빠른 참가를 선택합니다. 실제 경기는 방장 PC·브라우저가 처리하므로 방장은 경기가 끝날 때까지 연결을 유지해야 합니다. 일부 기업망이나 NAT에서는 운영자의 TURN 중계가 필요합니다.

현재 공용 로비 주소는 제공하지 않으며 운영 중인 서버가 필요합니다. Linux/NAS 설정 안내 · NAS/Linux 설정 ZIP · Cloudflare 무료 서버 구성. GitHub Pages는 게임 파일을 제공하며 실시간 방 목록 서버를 대신하지 않습니다.
