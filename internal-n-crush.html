Internal N Crush

함께 짜는 전술, 맞붙는 화력.
최대 32명이 즐기는 내부망 FPS. 6개 병과와 실내·실외 19개 전장에서 팀을 이루거나, 난이도를 골라 봇과 겨뤄 보세요.

Windows 다운로드 ↓

v0.7.0 · Windows 64비트 · ZIP · 개발 중인 알파 버전
소스 코드 · 변경 내용

1 / 3

시작하기

  1. ZIP을 모두 압축 해제합니다.
  2. InternalNCrush.exe를 실행합니다.
  3. 한 명이 방을 만들고, 나머지는 내부망 방 찾기에서 접속합니다. IP 주소로도 접속할 수 있습니다.
  4. 장비와 팀을 고른 뒤 방장이 시작합니다.

원하는 방식으로

팀 데스매치 · 개인전 · 제한 부활 · 거점 점령 · 폭탄 설치/해체.

방장이 병과·스킬 사용, 탄약, 중간 참가와 팀 재편성을 정합니다. 체력 자동 회복은 별도 옵션이며 기본으로 꺼져 있습니다.

봇과 연습하기

하 · 중 · 상 난이도와 인원, 맵, 모드를 선택하세요. 6인용 6개·8인용 6개·16인용 4개·32인용 3개 맵을 제공합니다.

봇은 목표를 점령하고 폭탄을 설치·해체하며, 병과에 맞춰 회복·수리·가젯·스킬을 사용합니다.

움직임과 전투의 변화

달리기 시작과 정지, 급회전 때 몸에 관성이 생기고 팔 스윙과 점프·착지·앉기가 자연스럽게 이어집니다. 총기·장구류·엄폐물·포탑의 세부 형태를 다듬고, 비조준 반동과 둔탁한 피격음을 강화했습니다.

킬 표시는 작고 반투명하게. 사망하면 공격자의 1인칭 상황을 2.5초 재구성한 뒤 1초 동안 공격자를 확대해 보여줍니다. 킬 리플레이는 SPACE 또는 ESC로 건너뛸 수 있습니다. 수신 기록을 재구성하므로 실제 공격자의 화면과 세부 차이가 있을 수 있습니다.

새 길과 자유로운 화면 설정

COURTYARD · SWITCHBACK · ROOFTOP · MARKET LOOP에 굽은 골목과 건물, 경사로와 높은 자리를 추가했습니다. 메인 메뉴에서도 실제 봇 6명이 전투합니다.

사용할 모니터를 고르고 창 모드·테두리 없는 전체 화면·독점 전체 화면을 전환하세요. 8K·울트라와이드 프리셋과 해상도 직접 입력을 지원합니다. 전체 화면은 선택한 모니터의 원본 해상도로 표시됩니다.

함께 접속하려면

같은 내부망에 연결하고, 참가자 모두 같은 버전을 사용하세요. 외부 인터넷 없이도 경기를 진행할 수 있습니다. 방이 검색되지 않으면 서버 IP를 입력하고 Windows 방화벽의 내부망 통신 허용 여부를 확인하세요.

게임 안의 설정 → 조작법에서 키보드·마우스 안내를 볼 수 있습니다. 감도·모니터·화면 모드·전체 음량 설정도 저장됩니다.
