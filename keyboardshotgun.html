KEYBOARD SHOTGUN

키보드 샷건

버튼 1~3개로 하는 5~20초짜리 미니게임을 이어서 겨루는 파티 게임입니다.
연타·반응·타이밍·기억·판단 미니게임 60여 가지가 라운드마다 무작위로 나오고, 뒤로 갈수록 빨라집니다.
한 방에 최대 32명이 함께하고, 사람이 모자라면 AI가 자리를 채웁니다.

Windows 10/11 64비트 · 인터넷(WAN) 접속 + 내부망(LAN) 접속

설치가 차단될 때

설치 파일에 코드 서명이 없어 Windows가 경고합니다. 악성 코드가 발견된 것은 아니며, 서명 없는 새 파일에 나타나는 기본 보호 기능입니다.

파란 창 "Windows의 PC 보호"

추가 정보를 누른 뒤 실행을 누르세요.

"스마트 앱 컨트롤이 이 앱을 차단했습니다"

파일마다 허용할 수 없습니다. 설치하려면 기능을 꺼야 합니다.

  1. 설정 → 개인 정보 및 보안 → Windows 보안을 엽니다.
  2. 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끔을 고릅니다.
  3. 설치 파일을 다시 실행합니다.

참고: 최신 Windows 11에서는 나중에 같은 곳에서 다시 켤 수 있지만, 다시 켜면 키보드 샷건도 실행이 막힙니다. 끄고 싶지 않으면 위 웹에서 바로 하기로 설치 없이 하세요(인터넷(WAN) 접속·혼자 하기 가능).

어떻게 하나요

시작

  1. 닉네임과 캐릭터 색을 정합니다.
  2. 방 만들기: 방 이름·비밀번호(선택)·라운드 수(3~30라운드)·AI 수를 정합니다. 방장은 참가하지 않고 큰 화면에 순위만 띄울 수도 있습니다.
  3. 방 목록: 인터넷(WAN) 방·내부망(LAN) 방(설치판)에서 원하는 방을 골라 들어갑니다. 방 번호로도 들어갈 수 있습니다.
  4. 대기실: 참가자는 「준비」를 누르거나 「관전」으로 구경만 할 수 있습니다. 방장은 「방장 넘기기」·「내보내기」를, 참가자는 「내보내기 투표」를 쓸 수 있습니다. 방장이 나가도 다른 사람이 이어받아 계속합니다.
  5. 경기 결과: 「다시 하기」로 같은 사람끼리 바로 한 경기 더. 1위가 동점이면 동점인 사람끼리 「동점 대결」을 한 번 더 합니다.
  6. 혼자 하기: AI와 바로 겨룹니다. 경기 중 게임 메뉴(Esc)에서 라운드 수를 바꿀 수 있습니다.

조작

  1. PC: ← ↓ → 또는 A S D. 버튼 하나만 쓰는 게임은 아무 키나·스페이스.
  2. 휴대폰: 화면 아래 큰 버튼(빨강○·파랑△·초록□).
  3. 라운드마다 규칙 한 줄이 먼저 나오고, 3·2·1 뒤에 시작합니다. 라운드 순위대로 1등 100점 ~ 꼴찌 10점.

알아 두기

  • 웹판은 인터넷(WAN) 접속만, 설치판은 내부망(LAN) 접속까지 됩니다. 내부망(LAN) 방은 공유기에 따라 기기끼리 연결되지 않을 수 있습니다.
  • 방장과 참가자 사이의 내용은 암호화되어 중계 서버도 볼 수 없습니다. 대기실 위의 확인 글자가 방장 화면과 같은지 서로 맞춰 보세요.
  • 회원 가입이나 개인 정보 입력이 없습니다. 닉네임·설정은 이 기기 브라우저에만 저장됩니다.
  • 설치판에 코드 서명이 없어 Windows가 경고할 수 있습니다. 설치 차단 안내를 보세요. 무료로 쓸 수 있고, 재배포와 판매는 할 수 없습니다. 이용 조건 전문
