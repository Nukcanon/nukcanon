# 이용약관·개인정보 처리방침 편집 안내

홈페이지의 [이용약관](https://nukcanon.github.io/nukcanon/terms.html)과 [개인정보 처리방침](https://nukcanon.github.io/nukcanon/privacy.html)은 이 폴더의 파일을 불러와 보여 줍니다. GitHub 웹에서 파일을 고치고 커밋하면 몇 분 뒤 홈페이지에 반영됩니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `meta.json` | 버전, 시행일, 마지막 문장(부칙), 조항 파일 목록 |
| `terms/` | 이용약관 조항. 한 파일에 한 조씩 |
| `privacy/` | 개인정보 처리방침 항목. 한 파일에 한 항목씩 |

페이지는 `meta.json`의 `sections`에 적힌 파일을 **파일 이름 순서**로 이어 붙입니다. 그래서 파일 이름 앞에 `01-`, `02-`처럼 두 자리 번호를 붙입니다.

## 조항 고치기

1. GitHub에서 `legal/terms/` 또는 `legal/privacy/`의 파일을 엽니다.
2. 연필 단추(Edit this file)를 눌러 고칩니다.
3. **Commit changes**를 누릅니다.

## 조항 추가하기

1. 해당 폴더에서 **Add file → Create new file**을 누릅니다.
2. 들어갈 자리에 맞게 이름을 정합니다. 예: 3조와 4조 사이라면 `03a-새조항.md`, 맨 끝이라면 `12-새조항.md`
3. 첫 줄에 `## 제12조 (제목)`처럼 제목을 쓰고 내용을 씁니다.
4. `meta.json`의 해당 `sections` 목록에 파일 이름을 추가합니다. 목록 순서는 상관없지만, 항목 사이의 쉼표(`,`)와 큰따옴표(`"`)를 빠뜨리지 않도록 주의하세요.

조 번호를 바꾸면 다른 조항에서 그 번호를 가리키는 문장(예: "2번 항목과 같이")도 함께 고쳐 주세요.

## 조항 지우기

파일을 지우고, `meta.json`의 `sections`에서도 그 이름을 지웁니다. 목록에만 있고 파일이 없으면 페이지에 "일부 조항을 불러오지 못했습니다"라는 안내가 나옵니다.

## 버전과 시행일 바꾸기

`meta.json`의 `version`과 `effective`를 고칩니다. `closing`의 `{시행일}`은 `effective` 값으로 바뀌어 표시됩니다.

## 쓸 수 있는 서식

| 쓰는 법 | 보이는 모양 |
|---|---|
| `## 제목` | 조항 제목(목차에 들어감) |
| `### 작은 제목` | 조항 안의 작은 제목 |
| `1. 내용` | 번호 목록 |
| `- 내용` | 점 목록. 앞에 공백 3칸을 넣으면 한 단계 안쪽 목록 |
| `**굵게**` | 굵은 글씨 |
| `[글자](https://주소)` | 링크 |
| `<이메일@주소>` | 이메일 링크 |
| `` `글자` `` | 코드 글씨 |
| `> 내용` | 강조 상자 |
| 표 (`\| 칸 \| 칸 \|` 다음 줄에 `\|---\|---\|`) | 표. 휴대폰에서는 칸 이름이 붙은 카드 모양으로 바뀜 |

빈 줄로 문단을 나눕니다. HTML 태그는 글자 그대로 표시됩니다.

## 참고

- 이전 내용은 각 파일의 **History**에서 볼 수 있습니다.
- 페이지 모양은 `../terms.html`, `../privacy.html`, `../css/legal.css`, 불러오는 방식은 `../js/legal.js`에 있습니다.
