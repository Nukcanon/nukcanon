## 2. 사이트 이용 시 처리되는 정보
1. 사이트는 쿠키를 이용하지 않으며, 방문 분석 도구 및 광고 도구를 이용하지 않음.
2. 사이트는 GitHub, Inc.가 운영하는 GitHub Pages를 통하여 호스팅됨. GitHub는 보안 목적으로 방문자의 IP 주소 등 접속 기록을 자체 방침에 따라 처리함. 운영자는 해당 기록을 제공받거나 열람할 수 없음.
3. 프로그램 설치 파일은 GitHub 릴리스를 통하여 배포됨. 운영자가 확인할 수 있는 정보는 파일별 다운로드 횟수의 합계에 한정됨.
4. Internal N Crush는 최신 버전 여부를 확인하기 위하여 사이트의 버전 정보 파일을 조회함. 이 과정에서 이용자에 관한 정보를 별도로 전송하지 않음.
5. 외부 사이트로 연결되는 링크를 이용하는 경우 해당 사이트의 개인정보 처리방침이 적용됨.
