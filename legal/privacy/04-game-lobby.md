## 4. Internal N Crush 온라인 로비
웹판의 온라인 로비 및 Windows판의 인터넷 로비는 운영자가 Cloudflare Workers에서 운영하는 로비 서버를 이용함. 로비 서버는 방 목록 제공, 입장 승인 및 직접 연결을 위한 신호 중계만 처리하며, 경기 데이터는 처리하지 않음.

| 처리 항목 | 처리 목적 | 보유 기간 |
|---|---|---|
| 닉네임(20자 이내), 게임 버전 | 동일 버전 간 방 목록 제공, 입장 처리, 동일 방 참가자에 대한 닉네임 표시 | 서버 저장소에 별도로 저장하지 않음. 이용자 단말기가 보관하는 접속 토큰(발급 후 6시간 경과 시 만료) 및 연결 유지 중의 연결 정보에만 포함됨. |
| 방 이름, 경기 설정, 참가 인원 | 공개 방 목록 표시 | 방장이 방을 종료하거나 방장의 연결이 45초 이상 끊긴 경우 삭제함. |
| IP 주소 | 과도한 요청 제한, 동일 네트워크 여부 확인 | 원본 IP 주소는 저장하지 않으며, 서버 비밀 키로 변환한 값만 이용함. 요청 제한 기록은 마지막 요청 후 약 5분 경과 시 삭제함. 변환한 값은 접속 토큰(6시간) 및 방 기록(방 종료 시까지)에도 포함됨. |
| 연결 식별용 임의 번호 | 이용자 연결 구분 | 접속 토큰 만료 시까지(6시간) |
| 직접 연결 정보(IP 주소 및 포트 포함) | 방장과 참가자 간 직접 연결 | 서버는 중계만 하며 저장하지 않음. |

- 빠른 참가 기능으로 방이 생성되는 경우 방 이름에 닉네임이 포함되어 공개 방 목록에 표시됨.
- 경기 중 이동, 사격 등 게임 데이터는 서버를 경유하지 않고 방장과 참가자 간 암호화된 직접 연결(WebRTC)로 송수신됨. 이에 따라 동일 방의 방장과 참가자는 기술적으로 상대방의 IP 주소를 확인할 수 있음.
- 직접 연결을 지원하기 위하여 Cloudflare의 STUN 서버(stun.cloudflare.com)에 접속함.
- 운영자는 로비 서버의 로그 저장 기능을 비활성화하여 접속 기록을 별도로 수집하지 않음. 다만, Cloudflare는 서비스 운영 및 보안 목적으로 자체 방침에 따라 접속 정보를 처리할 수 있음.
- Windows판의 내부망 로비는 동일 네트워크 내 컴퓨터 간 직접 연결 방식으로, 운영자의 서버를 이용하지 않음. 제3자가 별도로 운영하는 로비 서버(NAS/Linux)는 해당 운영자가 관리함.
