NUKLEAR VANGUARD

도트 그림으로 만든, 옆으로 달리며 쏘는 액션 게임입니다.
적의 핵 공격을 막으러 섬에 상륙한 네 대원이 해안·안개 강·산악 열차·점령된 수도·설원 요새·발사 시설까지 미션 6개를 돌파합니다.
무기를 주워 바꾸고, 탈것과 보스를 부수고, 붙잡힌 사람을 구하세요.

Windows 10/11 64비트 · 키보드 · 인터넷(WAN) 접속 + 내부망(LAN) 접속

설치 없이 바로 시작

설치가 차단될 때

설치 파일에 코드 서명이 없어 Windows가 경고합니다. 악성 코드가 발견된 것은 아니며, 서명 없는 새 파일에 나타나는 기본 보호 기능입니다.

파란 창 "Windows의 PC 보호"

추가 정보를 누른 뒤 실행을 누르세요.

"스마트 앱 컨트롤이 이 앱을 차단했습니다"

파일마다 허용할 수 없습니다. 설치하려면 기능을 꺼야 합니다.

  1. 설정 → 개인 정보 및 보안 → Windows 보안을 엽니다.
  2. 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끔을 고릅니다.
  3. 설치 파일을 다시 실행합니다.

참고: 최신 Windows 11에서는 나중에 같은 곳에서 다시 켤 수 있지만, 다시 켜면 NUKLEAR VANGUARD도 실행이 막힙니다. 끄고 싶지 않으면 위 웹에서 바로 하기로 설치 없이 하세요.

어떻게 하나요

시작

  1. 게임 시작 → ARCADE: 미션 1부터 차례로. 목숨과 점수가 이어집니다.
  2. MISSION SELECT: 원하는 미션과 시작 자리를 골라 연습합니다. 점수는 기록하지 않습니다.
  3. 캐릭터 4명 중 한 명을 고릅니다. 캐릭터마다 기술이 다릅니다.
  4. 목숨을 다 잃으면 이어하기(CONTINUE)로 계속할 수 있습니다.

조작(키는 환경 설정에서 바꿀 수 있음)

  1. 혼자 할 때(1인 키): W·A·S·D 이동·조준(S 엎드리기) · J 쏘기 · K 점프 · L 수류탄 · I 기술 · U 총 바꾸기
  2. 방향키 방식(환경 설정 → 키 설정 → 조작 방식): 방향키 이동·조준 · A 쏘기 · S 점프 · D 수류탄 · F 기술 · R 총 바꾸기. 둘이 할 때는 1P와 2P의 키가 서로 바뀝니다.
  3. 한 컴퓨터로 둘이 할 때(2인 키): 1P W·A·S·D 이동·조준 · F 쏘기 · G 점프 · H 수류탄 · T 기술 · R 총 바꾸기 / 2P 방향키 · 숫자패드 1 쏘기 · 2 점프 · 3 수류탄 · 0 기술 · 4 총 바꾸기. 게임패드도 쓸 수 있습니다.
  4. Esc 일시정지(게임 메뉴)
  5. 웹판 전체 화면: 오른쪽 위 전체 화면 단추. 끝낼 때는 Esc를 길게 누르거나 단추를 누릅니다.

둘이서 하기

  • 한 컴퓨터: 메뉴의 「둘이서 하기」에서 고르면 한 키보드(또는 게임패드)로 둘이 함께 합니다. 웹판과 설치판 모두 됩니다.
  • 인터넷(WAN) 방: 웹판과 설치판 모두에서 됩니다. 방을 만들고 방 번호를 알려 주면 상대가 방 목록이나 번호로 들어옵니다. 로비 서버는 연결을 소개만 하고, 게임 데이터는 두 컴퓨터 사이로만 오갑니다.
  • 내부망(LAN) 방: 설치판에서만 됩니다(웹판은 인터넷(WAN) 방만). 같은 공유기에 붙은 두 컴퓨터가 방 목록에서 서로를 찾습니다. 공유기 설정에 따라 기기끼리 연결되지 않을 수 있고, Windows 방화벽이 처음 물으면 「개인 네트워크 허용」을 고르세요.

알아 두기

  • 웹판은 페이지를 열면 게임 파일(약 90 MB)을 내려받고, 다 받으면 「게임 시작」이 켜집니다. 휴대폰·태블릿은 화면 조작이 없어 키보드가 필요합니다.
  • 회원 가입이나 개인 정보 입력이 없습니다. 설정과 기록은 이 기기(웹판은 이 브라우저)에만 저장됩니다.
  • 설치판에 코드 서명이 없어 Windows가 경고할 수 있습니다. 설치 차단 안내를 보세요. 무료로 쓸 수 있고, 재배포와 판매는 할 수 없습니다. 이용 조건 전문
