SCHOOL ASSIGNMENT

교내 과제 제출 시스템

학교 안 서버로 과제를 내고, 쓰고, 제출하는 프로그램입니다.
학생·교사 PC에는 접속 프로그램 교내 과제 제출을, 서버로 쓸 Windows PC에는 교사용 설치 프로그램을, 시놀로지 NAS·Linux 서버에는 NAS·Linux용 서버 패키지를 설치합니다.

학생용 설치 프로그램 ↓

Windows 10/11 64비트 · 약 0.4MB
학생·교사 PC용 접속 프로그램

교사용 설치 프로그램 ↓

Windows 10/11 64비트 · 약 60MB
서버 PC용, 다시 실행하면 업데이트

NAS·Linux용 서버 패키지 ↓

시놀로지 NAS(DS423+ 등)·일반 Linux · 약 0.3MB
64비트 Intel·AMD, 64비트 ARM

간단한 사용법

학생

  1. 선생님이 준 배포 묶음(ZIP)이 있으면 압축을 모두 풀고 그 안의 설치 파일을 실행합니다. 없으면 학생용 설치 프로그램을 실행합니다.
  2. 바탕화면의 교내 과제 제출을 열고 선생님이 알려 준 서버 주소를 넣습니다.
  3. 처음에는 최초 비밀번호 설정에서 아이디, 초기코드, 새 비밀번호를 입력합니다.
  4. 내 과제 → 과제 열기에서 답을 쓰고 최종 제출을 누릅니다. 제출 확인증이 열리면 끝입니다.

교사

  1. 학교 안에서 늘 켜 둘 Windows PC(서버 PC)에 교사용 설치 프로그램을 설치합니다. NAS·Linux 서버를 쓰려면 아래 「NAS·Linux 설치 순서」를 따릅니다.
  2. 설정 화면에서 DB, 웹 관리자, 접속 방식(기본 HTTPS)을 정합니다.
  3. 바탕화면의 교내 과제 제출 시스템으로 서버를 켜고, 관리자 페이지에 로그인해 OTP를 등록합니다.
  4. 교사관리·학생관리에서 계정을 만들고, 교내 과제 제출 시스템의 접속 프로그램 배포 묶음 만들기로 만든 ZIP을 학생에게 나눠 줍니다.

NAS·Linux 설치 순서

NAS·Linux용 서버 패키지는 아래 순서로 설치합니다.

  1. NAS·Linux용 서버 패키지(ZIP)를 받아 모두 풀고, Windows PC에서 01_설정.cmd를 실행합니다. 브라우저 설정 화면이 열리며, NAS 종류(인텔·AMD 또는 ARM)를 고릅니다.
  2. 설정을 마치면 만들어지는 ready_to_upload/SchoolAssignmentServer_deploy.zip을 NAS의 docker 폴더에 올리고 그 자리에서 압축을 풉니다.
  3. NAS의 Container Manager → 프로젝트 → 생성으로 프로젝트를 만듭니다. 프로그램 이미지는 이때 자동으로 내려받으며, 처음에는 시간이 걸릴 수 있습니다.
  4. 설정 화면 마지막의 순서표(PDF)대로 역방향 프록시와 관리자 OTP를 설정합니다.

일반 Linux 서버는 압축을 푼 폴더에서 sudo sh 02_start.sh --install-docker를 실행합니다(Docker 설치 후 서버 시작).

알아 두기

  • 배포 묶음에는 학교 인증서와 서버 주소가 들어 있습니다. 웹에서 받은 설치 파일만으로 설치하면 인증서 오류로 접속이 막힐 수 있습니다.
  • 자세한 사용법은 로그인 후 위 메뉴의 사용방법과 서버 PC 시작 메뉴의 사용설명서에 있습니다.
  • NAS·Linux용 패키지는 64비트 Intel·AMD(amd64)와 64비트 ARM(arm64)용 프로그램 이미지를 씁니다. 32비트 ARM 기기는 지원하지 않습니다. 설치 중에는 인터넷 연결이 필요합니다.
