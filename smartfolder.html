SMART FOLDER

SmartFolder

복잡하게 쌓인 폴더를 분석해 게임·프로그램·문서·사진·영상 등 종류별로 정리하는 Windows 프로그램입니다.
옮기기 전에 정리 계획을 먼저 보여 주고, 확인한 뒤에만 옮기며, 끝난 정리는 언제든 되돌릴 수 있습니다.

설치 프로그램 ↓

Windows 10/11 64비트 · 약 8MB
AI는 첫 실행 때 따로 받습니다

간단한 사용법

처음 시작

  1. 설치 프로그램을 실행합니다. 모든 사용자용 또는 이 사용자용 설치를 고를 수 있습니다.
  2. 처음 열면 앱 암호를 정합니다. 정리 기록·색인·태그는 이 암호로 잠가 PC 안에만 저장합니다.
  3. 폴더 추가로 정리할 폴더를 등록합니다. 여러 폴더를 함께 관리할 수 있습니다.
  4. 처음 잠금을 풀면 로컬 AI(번역·요약·이름 제안·애매한 파일 판정)를 자동으로 받습니다. 설정에서 끌 수 있습니다.

정리하기

  1. 폴더를 고르고 정리를 누르면 정리 계획이 만들어집니다.
  2. 계획에서 어디로 옮겨지는지 확인합니다. 판단이 애매한 것은 확인 필요로 따로 표시됩니다.
  3. 확인하고 실행하면 기록을 남기며 옮깁니다. 도중에 PC가 꺼져도 다음 실행 때 이어서 마무리합니다.
  4. 결과가 마음에 들지 않으면 작업 기록에서 되돌리기를 누릅니다. 되돌리기 기록은 설정에서 정한 기간(기본 90일) 동안 보관합니다.

개인 정보 보호

  • 파일 이름·경로·내용을 외부로 보내지 않습니다. AI는 PC 안에서만 실행됩니다.
  • 인터넷을 쓰는 것은 AI 엔진·모델을 받을 때와, 사용자가 켠 온라인 찾기뿐입니다. 온라인 찾기는 기본으로 꺼져 있고, 보내기 전에 보낼 내용을 매번 보여 줍니다.
  • 게임 폴더는 안쪽을 나누지 않고 한 묶음으로 옮깁니다. 확인 없이 옮기거나 지우는 일은 없습니다.

알아 두기

  • 설치 파일에 코드 서명이 없어 Windows가 실행을 막을 수 있습니다. 아래 설치가 차단될 때를 따르세요.
  • 로컬 AI는 PC 사양에 맞춰 약 3GB(4B) 또는 약 6GB(9B)를 받습니다. 그래픽 카드가 없거나 맞지 않으면 CPU로 실행합니다.
  • 앱 암호를 잊으면 저장된 기록을 열 수 없습니다. 파일 자체는 그대로 남습니다.
  • 버전 0.1.3 · 파일 확인값(SHA-256) 목록 · 이용 약관(텍스트 파일)
  • 내려받은 파일이 맞는지 확인하려면 PowerShell에서 Get-FileHash 파일이름을 실행해 아래 값과 비교하세요.

설치가 차단될 때

설치 파일에 코드 서명이 없어 Windows가 경고합니다. 악성 코드가 발견된 것은 아니며, 서명 없는 새 파일에 나타나는 기본 보호 기능입니다.

파란 창 "Windows의 PC 보호"

추가 정보를 누른 뒤 실행을 누르세요.

"스마트 앱 컨트롤이 이 앱을 차단했습니다"

파일마다 허용할 수 없습니다. 설치하려면 기능을 꺼야 합니다.

  1. 설정 → 개인 정보 및 보안 → Windows 보안을 엽니다.
  2. 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정에서 끔을 고릅니다.
  3. 설치 파일을 다시 실행합니다.

참고: 최신 Windows 11에서는 나중에 같은 곳에서 다시 켤 수 있지만, 다시 켜면 이 프로그램도 실행이 막힙니다.
